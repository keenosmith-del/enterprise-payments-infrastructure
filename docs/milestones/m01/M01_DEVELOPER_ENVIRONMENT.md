# M01 developer environment

Prerequisites are Git, Python 3.14, Node.js 24, npm, Docker with a running daemon, Docker Compose and OpenSSH client utilities. From the repository root, `make bootstrap` creates ignored development credentials, creates `.venv`, installs the hashed Python lock and runs `npm ci`. `make up` builds and starts the core stack. The default frontend URLs are `http://127.0.0.1:5173`, `http://127.0.0.1:5174`, `http://127.0.0.1:5175` and `http://127.0.0.1:5176`. The respective backend ports are 8001 through 8004. Keycloak is at port 8180.

The synthetic user is `synthetic-user`; its generated password is the `EPI_KEYCLOAK_USER_PASSWORD` entry in `.local/epi.env`. Treat that file as local confidential material. `make status`, `make logs`, `make migrate`, `make seed` and `make down` provide operating commands. The migration command also performs idempotent foundation seeding. Normal shutdown does not remove data. Removing named volumes is destructive and must be invoked explicitly.

For SFTP, first run `scripts/m01/create_sftp_keys.sh`, then use `docker compose --env-file .local/epi.env --profile sftp up -d sftp`. Verify the generated host public key before connecting. The messaging infrastructure is part of the core stack. Profiles named `integration`, `analytics` and `observability` provide one-shot technical integration and analytics probes and Prometheus/Grafana services. `make verify` starts the local stack and runs static checks, dependency audit, frontend builds, authenticated browser and service checks, SFTP checks, optional observability service readiness and a disposable PostgreSQL privilege suite. It uses loopback ports 55433, 55434, 55672 and 2222 in addition to the core ports, and starts disposable containers for the M00 service probes. The separate hosted M00 workflow also runs those regressions; do not treat an unrun check as a pass.

## Resource planning and host development

The default long-running core container memory caps total approximately 3.5 GiB. Three one-shot setup containers may use up to another 1.5 GiB during bootstrap. The optional SFTP and observability services add approximately 0.75 GiB of caps, and the analytical and integration jobs may add another 0.75 GiB while running. These are configured caps, not measured usage; reserve additional memory for the operating system, Docker, builds and browsers. Image and browser downloads also need free disk space. Override the documented `EPI_*_MEMORY_LIMIT` Compose variables when the host requires different limits.

The frontend development servers bind to loopback ports 5173 through 5176 and proxy API requests to the corresponding backend ports 8001 through 8004. For example, after installing dependencies and starting the identity and database services, use `npm run dev --workspace=@epi/payments-hub` for the Hub frontend. `VITE_BACKEND_TARGET` can change its development proxy target. A host-run backend requires its own database URL and OIDC environment configuration; it must use the corresponding restricted runtime identity. Avoid exposing development identities outside loopback.
